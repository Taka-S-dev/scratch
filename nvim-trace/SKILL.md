# nvim-trace

利用者の Neovim は、トレースファイル（1 行 1 手順の JSON Lines）を読んで、
コードの各行の上に見出しと解説を重ね、右のパネルに手順を木の形で並べる。
ファイルが書き足されるとその場で表示が増えるので、**調べながら 1 手順ずつ追記する**。

## 置き場所

Neovim のデータディレクトリの下の `traces/<内容が分かる名前>.jsonl`。

- Windows: `%LOCALAPPDATA%\nvim-data\traces\`
- macOS / Linux: `~/.local/share/nvim/traces/`
- 確かめるには `nvim --headless -c "lua io.stdout:write(vim.fn.stdpath('data'))" -c q`
- フォルダが無ければ作る

ファイルの扱い:

- 調査 1 件につき 1 ファイル。名前は英小文字とハイフン（例: `srtp-crash.jsonl`）
- 同じ調査の続きなら同じファイルに追記する。別の調査なら新しいファイルにする
  （新しいファイルができると、表示は自動でそちらに切り替わる）
- **調べているソースには何も書き込まない**（作業コピーを汚さない）

## 書き方

1 行目は見出し（`line` を持たない行）:

```json
{"title": "SRTP の拡張で落ちる経路", "root": "<調べているリポジトリの絶対パス>"}
```

その後、手順を 1 行ずつファイルの末尾に足す:

```json
{"id": "entry", "file": "ssl/statem/extensions_srvr.c", "line": 120, "text": "if (!tls_parse_ctos_use_srtp(s, pkt, context, x, chainidx))", "title": "拡張を読むところ", "note": "use_srtp 拡張があるとここに来る。"}
{"id": "len", "parent": "entry", "file": "ssl/d1_srtp.c", "line": 60, "text": "len = strlen(ptr);", "title": "len の計算", "note": "col が NULL のとき ...", "kind": "cause"}
```

| キー | 中身 |
|---|---|
| `file` / `line` | 必須。`root` からの相対パスか絶対パス。`line` は 1 始まりで、**実際にファイルを開いて確かめた行番号** |
| `text` | **必ず書く**。その行に書いてあることを、ファイルから写す（行全体か、8 文字以上の特徴的な一部）。行番号がずれていても、表示側がこれで正しい行を探し直す。見つからないと警告が出るので、行番号の書き間違いにも気づける |
| `title` | パネルに出る見出し。20 字前後で「何をする所か」 |
| `note` | その行の上に出る解説。改行は `\n`。長くても窓の幅で折り返される |
| `kind` | `cause`（原因と確定）/ `suspect`（怪しいが未確定）/ 省略（普通の手順） |
| `id` / `parent` | 枝分かれするときだけ使う。`parent` に別の手順の `id` を書くとその下に付く。省略すると最上位に、書いた順で並ぶ |

JSON は 1 手順 1 行で、途中に改行を入れない。日本語などはそのまま UTF-8 で書く。
見出しと解説は、利用者が話している言語で書く。

## 手順の選び方

- 読む人は、自分では全体を読み解けない前提で書く。**入口から原因まで、読む順に**並べる
  （呼び出しの順、データが流れる順）
- 1 手順 = 1 か所。「この行で何が起きて、なぜ次の手順に行くのか」を `note` に書く
- 本筋は最上位に順番に並べる。脇道（別の呼び出し元、値の出どころ、構造体の定義）は
  `parent` で枝にするか、本筋の後ろに回す。本筋の途中に脇道を挟まない
  （次の手順へ進むキーは、パネルの並び順に進むため）
- 原因が確定したら `kind: "cause"`。確信が無い所は `suspect` にし、根拠と不確かさを `note` に書く
- 行番号を推測で書かない。検索や定義ジャンプの道具で見つけ、ファイルを読んで行を確かめてから書く。
  `text` はそのとき読んだ行から写す（記憶から書かない）
- 書き終えたら、ファイルを読み直して、各手順の行が意図した行を指しているか確かめる
- 調べ終えたら、チャットでは要約と結論だけを言う（詳細はトレースにあるので繰り返さない）
