# nvim-trace

大きなコードの道筋（不具合の経路など）を、AI エージェントに調べさせて Neovim の
コードの上に解説付きで出すためのスキル。エージェントはトレースファイル
（1 行 1 手順の JSON Lines）を書くだけで、表示は Neovim 側が受け持つ。

- `SKILL.md`: エージェントに読ませる指示。`name` と `description` だけを持つ
  共通の書式なので、Claude Code、Codex、GitHub Copilot など、この書式の
  スキルを読めるエージェントで使える

## 入れ方

`nvim-trace` フォルダごと、使うエージェントのスキルのフォルダに置く
（コピーでもリンクでもよい）。

- Claude Code: `~/.claude/skills/nvim-trace/`
- そのほかのエージェント: それぞれの説明書にあるスキルのフォルダ

## Neovim 側

トレースファイルを読んで表示する設定が要る。`SKILL.md` の「書き方」が
ファイルの形式のすべてなので、それを読んで表示できる設定であればよい。
